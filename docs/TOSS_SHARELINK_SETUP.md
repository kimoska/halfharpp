# 토스쇼핑 쉐어링크 입력

이 프로젝트는 토스쇼핑 제휴 페이지에서 사용자가 직접 발급한 링크를 사용합니다. 현재 확인 가능한 공개 문서에는 토스 미니앱 공유 링크 API가 있으나, 토스쇼핑 제휴상품을 자동 검색·선정하고 제휴 링크를 발급하는 공개 API는 확인되지 않았습니다.

`data/products.csv`에 아래 값을 입력합니다.

- `id`: 내부에서 사용할 고유값
- `name`: 상품명
- `category`: 생활용품 등 분류
- `affiliate_url`: 토스에서 발급한 실제 쉐어링크
- `price`: 확인한 현재 가격
- `price_checked_at`: ISO 형식 확인 시각, 예: `2026-09-11T18:30:00+09:00`
- `active`: 게시 후보로 쓰려면 `true`
- `notes`: 옵션·배송비·주의사항

가격 확인 후 24시간이 지나면 자동 게시되지 않습니다. 가격을 다시 확인하고 `price`와 `price_checked_at`을 갱신해야 합니다.

처음 상품을 활성화한 뒤 미래 계획에 제휴 글을 넣습니다.

```powershell
npm run start -- reseed --days 30
```

이후 CSV의 가격·링크·확인 시각은 매 예약 실행 직전에 기존 제휴 초안으로 자동 동기화됩니다.

토스 제휴 프로그램 자체의 최신 이용약관, 금지 매체, 문구, 링크 변형 허용 여부는 계정 화면의 약관을 최종 기준으로 확인해야 합니다.
