# 하프하프 모하프 콘텐츠 운영안

## 계정 약속

“필요한 생활 정보를 말랑하게 정리하고, 정말 살펴볼 만한 물건만 가끔 소개하는 하프물범.”

캐릭터 자체가 광고판이 되면 팔로우 이유가 사라집니다. 기본 구성은 정보 40%, 공감 30%, 질문·참여 20%, 제휴 10%입니다. 제휴 글 사이에는 일반 글을 최소 3개 둡니다.

## 콘텐츠 기둥

1. 생활 정보: 가격 비교, 후기 읽는 법, 정리·절약 습관
2. 소비 공감: 장바구니, 무료배송, 택배, 충동구매 에피소드
3. 참여 질문: 밸런스 게임, 선택 질문, 실패담 모집
4. 솔직 추천: 누구에게 맞는지와 안 맞는지, 확인 시각, 링크

## 문체

- 첫 문장은 짧은 관찰 또는 질문
- 한 게시물에는 메시지 하나만
- 실제로 써보지 않았다면 “사용해봤다”고 쓰지 않음
- 최저가·완벽·무조건·품절임박 등 검증 곤란한 표현 금지
- 구매 압박보다 “필요한 사람만 확인”을 사용
- 정보 글에도 댓글을 부르는 질문을 하나 포함

## 제휴 글 필수 요소

- 첫 화면에서 알아볼 수 있는 `[광고]` 표시
- 링크를 통한 구매 시 수수료를 받을 수 있다는 설명
- 가격을 쓸 경우 확인한 날짜와 최종 가격 재확인 안내
- 장점만이 아니라 대상·제약·확인 사항 포함
- 링크가 실제 토스쇼핑 쉐어링크인지 수동 확인

## 4주 운영 목표

- 1주차: 캐릭터·공감 중심, 댓글이 나오는 질문 탐색
- 2주차: 저장되는 정보형 포맷 2개 선정
- 3주차: 반응 좋았던 주제와 연관된 제휴 글 1~2개 테스트
- 4주차: 조회수보다 프로필 방문·링크 클릭·댓글률을 비교

반응이 낮은 형식은 자동 생성량을 줄이고, 댓글이 붙는 질문과 저장되는 정보 포맷을 늘립니다.
