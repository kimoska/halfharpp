# 실제 게시 전 최종 점검

- [ ] 하프하프 모하프 계정 프로필과 소개 문구 확정
- [ ] Meta Threads 앱 생성 및 테스터 초대 수락
- [ ] `threads_basic`, `threads_content_publish` 권한 토큰 입력
- [ ] 공개 이미지 URL을 브라우저 시크릿 창에서 열어봄
- [ ] 실제 토스 쉐어링크 입력 및 `active=true`
- [ ] 가격과 옵션을 게시 당일 다시 확인
- [ ] 제휴 프로그램 최신 약관에서 Threads 게시 허용 여부 확인
- [ ] `npm test`, `npm run typecheck`, `npm run validate` 통과
- [ ] `npm run dry-run`에서 문안과 카드 이미지 확인
- [ ] 일반 글 한 건으로 실제 게시 테스트
- [ ] 제휴 글 한 건을 직접 승인해 광고 고지·링크 이동 확인
- [ ] 이상 없을 때 `LIVE_PUBLISH_ENABLED=true`
- [ ] `config/automation.json`의 `dryRunByDefault=false`
- [ ] Windows 예약 작업 설치

위 항목 중 계정·토큰·제휴 약관·실제 링크는 본인 확인이 반드시 필요합니다.
